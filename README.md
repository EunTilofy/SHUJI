# 数迹

支持单人挑战与实时多人竞赛的多目标数字 Wordle 游戏。

## 玩法

系统生成 `N` 个互不相同的 `M` 位数字字符串（允许前导零）。玩家每轮提交一个 `M` 位数字，所有尚未猜中的目标都会返回反馈：

- 绿色：数字和位置均正确
- 橙色：数字存在，但位置错误；重复数字按剩余次数匹配
- 灰色：数字不存在，或该数字的可匹配次数已经用完

猜中目标后，该列停止产生提示。找到全部目标或耗尽轮次后结束。

轮次上限为 `N + ceil(log2(M)) + 3`，并限制在 6 到 24 轮之间。公式以单块反馈的信息论下界 `log(10) / log(3) ≈ 2.1` 为基础，再加入重复数字定位、逐个命中与人类操作余量。常用的 `N=4, M=8` 配置为 10 轮。

## 多人模式

房主创建六位房间代码，最多 30 位玩家加入后统一开始。所有玩家面对同一组答案并独立作答。比赛中只公开排名、已找到数量和已用轮数，不公开具体猜测；所有玩家结束后，可逐一查看每个人的完整棋盘。

## 运行

```bash
npm install
npm test
npm start
```

默认监听 `0.0.0.0:6357`，可通过 `PORT` 和 `HOST` 环境变量覆盖。已完成比赛保存在 `data/results.json`，最近保留 100 场。
